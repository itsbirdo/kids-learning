## Goal
A repo skeleton where content, app, tools and gateway can each be built and tested from day one. A fresh clone should reach "app running on the tablet" by following one guide.

## Repo layout
```
app/                      Flutter app (Android first; ios/ folder present, unused until #23)
  lib/
    main.dart
    app/                  router, theme, bootstrap
    domain/               pure Dart: lesson engine, SRS, scoring decisions, matcher
    data/                 content catalog, progress DB (drift), settings
    platform/             interfaces + Android impls: audio, recorder, recognizer, tts, secure storage
    features/             home, session, activities/, rewards, parent/
  android/                incl. Kotlin Vosk bridge (#16)
  assets/content/         GENERATED by `kl build`: content.json, audio/, images/, grammar.json
  test/  integration_test/
content/                  Source of truth for lessons (YAML), see #5/#6
  units/  global/  schema/
  local/                  gitignored: family.yaml (kids' names), never committed
tools/                    Python (uv) CLI "kl": validate, build, audio, images, eval (#6/#7/#8/#19)
gateway/                  Cloudflare Worker (TypeScript) (#18)
docs/                     plan, ADRs, research, guides, issue specs
.github/workflows/        CI
CLAUDE.md                 conventions + commands for AI coding agents
```

## Spec
**Flutter app**
- Create it with `flutter create --org com.itsbirdo --project-name kids_learning --platforms android,ios app`.
- `applicationId`: `com.itsbirdo.kidslearning`.
- `minSdk` 26 (Android 8). Vosk and sherpa-onnx need only 21; lower it if the kids' tablet is older (#4).
- Keep `targetSdk` at the template default.
- Landscape-first tablet layout; lock orientation in the session screens.
- Lints: `very_good_analysis` or `flutter_lints` plus `dart format` in CI.
- Dev-only values go in `app/.env.local.json`, read with `--dart-define-from-file`. That file is gitignored.

**Tools**
- Python 3.12 managed with `uv`.
- Package `tools/kl`: a Typer CLI with the subcommands stubbed (`validate`, `build`, `audio`, `images`, `eval`).
- `ruff` and `pytest`.

**Gateway**
- `gateway/` holds wrangler, TypeScript and vitest. Only a "hello" route for now; real work is in #18.

**Git**
- Git LFS for `app/assets/content/audio/**` (`*.m4a`) and images (`*.png`). Check the GitHub LFS free quota *(verify)*.
- `.gitignore` covers secrets, keystores, `content/local/`, `recordings/`, and `*.wav` outside `tools/tests/fixtures/`.

**CI (GitHub Actions, ubuntu-latest, path-filtered, cached)**

| Job | Steps |
|---|---|
| `app` | `flutter analyze`, `flutter test`, `flutter build apk --debug`, upload the APK as an artifact |
| `content` | `uv run kl validate` |
| `tools` | `ruff`, `pytest` |
| `gateway` | `npm ci`, `tsc --noEmit`, `vitest run` |

**Docs**
- `docs/dev-setup.md` covers:
  - installing Flutter and Android Studio
  - `flutter doctor`
  - enabling Developer options and USB debugging on the tablet
  - `flutter run`
  - wireless debugging (Android 11+)
- `CLAUDE.md` covers layout, commands, the privacy rules from #24, and the issue/PR conventions.
