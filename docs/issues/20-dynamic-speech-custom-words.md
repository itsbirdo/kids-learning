**Phase 4 · Size M (L with Piper) · Depends on: #7, #10, #14, #18 · Optional**

## Goal
Speak things that weren't pre-generated, in the same voice where possible:
- kids' names
- words a parent adds, e.g. this week's school vocabulary
- emergency fallback for any missing clip

## Tiers
| Tier | When | How |
|---|---|---|
| 1. Pre-generated | Default | Name lines ("¡Muy bien, {name}!") generated by #7 from `content/local/family.yaml` (gitignored) |
| 2. Online, same voice | Parent adds a custom word or phrase | Gateway `POST /v1/tts` (#18) → Azure TTS with the house voice and SSML template → mp3 cached in app storage. Consistent with the bundle |
| 3. Offline fallback | No network, or a missing clip | Android system TTS through `flutter_tts` (Google es-MX / es-US / es-ES voice). The parent area prompts to install the Spanish voice data |
| 4. Offline, consistent (stretch) | Fully offline custom words | `sherpa_onnx` 2.0.x with Piper `vits-piper-es_MX-claude-high` (about 60–75 MB, *verify*) |

## Parent custom word lists (parent area, #14)
- **Each word needs:**
  - Spanish text with its article
  - English gloss
  - a picture: emoji search in the bundled set, or a photo taken on the device (stays local)
- **Distractors** are suggested on the device using the Dart phonetic key (#6/#16).
- **Speech check:**
  - if the word is outside the Vosk vocabulary, mark it `azure_only`;
  - when offline, it becomes "listen to yourself" practice with no check.
- **Lists** appear as a special unit, "Mis palabras", and join the SRS (#12) like any other item.

## Piper notes (only if tier 4 is built)
- **sherpa-onnx 2.0.0 removed espeak-ng.** Text must arrive as phonemes, or through a lexicon. Options:
  - **Build-time lexicon:** `kl lexicon` runs espeak-ng (`es-419` or `es`) on the dev machine for every known word. No GPL code ships.
  - **Runtime custom words:** `piper_phonemize` (**GPL-3.0**: fine for a family app, blocks any publishing), or pin sherpa-onnx **1.13.8**, the last version with espeak-ng.
- Piper is about 9× faster than Kokoro on CPU, and Kokoro's sherpa model has only two Spanish voices.
- **Kokoro:** re-evaluate only after a listening test. Its Spanish voices are ungraded, learned Castilian phonemes, and are weak on utterances under 10–20 tokens.
